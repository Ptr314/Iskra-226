# Инструментарий исследования формата

Питоновская модель разбора файлов BASIC 02. Проверена на всём корпусе:
94 файла, 15 735 строк, разбор без единой рассинхронизации.

Сам корпус в репозиторий не входит; всё здесь ищет его в `corpus/hex/` и
`corpus/bin/`.

Служит двум целям: исследование формата и оракул для дифференциального
тестирования будущего эмулятора.

## Основные модули

| Файл | Назначение |
|---|---|
| `iskra.py` | загрузчик hex-дампов, сборка потока из секторов, разбиение на записи строк и операторы |
| `detok.py` | таблицы токенов, автомат состояний, модель переменных из таблиц 1/2/3, рендеринг листинга |
| `nb.py` | то же для двоичных файлов из `corpus/bin` |
| `hex2bin.py` | `corpus/hex/*_bin.txt` → `build/corpus/*.bin` |
| `detok_min.py` | выемка детокенизатора отдельным пакетом (см. ниже) |

## Просмотр

```
py show.py STAT09          листинг с текстовой парой, если она есть
py raw.py EDITOR 265       сырые байты указанных строк
py line.py STAT09 100,120  отдельные строки с разбивкой на операторы
py clean.py <файл>         снять HTML-экранирование с вывода C++ вьюера
```

## Сверка

Сверка сравнивает вывод C++ детокенизатора с эталонными листингами, поэтому
сначала нужно его прогнать (см. `tmain.cpp` ниже) и сложить результат в
`build/out/` — корпус из hex-дампов, и `build/out2/` — корпус `corpus/bin`.


```
py verify.py               построчное сравнение всех пар «текст + токены»
py cmp.py STAT09 10        первые 10 расхождений в одной паре
py vdet.py skel EDITOR 5   детали расхождений по видам (skel / lits / nums)
```

`verify.py` сравнивает три проекции строки: «скелет» (знаки препинания после
удаления имён, чисел и литералов), содержимое строковых литералов и
содержимое `HEX(…)`. Имена переменных в токенизированном файле не хранятся,
поэтому сравнивать их бессмысленно.

## detok_min.py

Выемка детокенизатора для другого проекта: шесть пар файлов из `src/core/`
(`detokenize`, `byte_source`, `expr`, `names`, `number`, `program`) и больше
ничего. Текстовая форма программы при этом оглушается — за ней тянутся
`tokenize.*` и `text_lexer.*`, а обратной трансляции транслятор не нужен
вовсе.

```
py tools/detok_min.py [КУДА]          по умолчанию build/detok-min
g++ -std=c++11 -I. -o detok example.cpp core/*.cpp
```

Вложить в чужой проект с его раскладкой каталогов — ключом `--prefix`: файлы
лягут прямо в `КУДА`, а включаться будут указанным путём.

```
py tools/detok_min.py …/dsk_tools/src/viewers/iskra226 --prefix viewers/iskra226
```

Второй редакции файлов скрипт не держит: он копирует их из эмулятора и
отказывается собирать пакет, если хоть один из них потянул что-то сверх
шестёрки. Проверено сверкой со всем корпусом — на 93 оттранслированных
файлах листинг совпадает с выдачей `iskra-nohead --detok` побайтово,
а единственный текстовый (`FS`) пакет отвергает, как и задумано.

## tmain.cpp

Автономный стенд для C++ детокенизатора из DISK Commander — собирается с
`dsk_tools` и прогоняет весь корпус мимо Qt:

```
g++ -std=c++11 -o tview tmain.cpp \
    <dsk_tools>/src/viewers/viewer_basic_iskra226.cpp \
    <dsk_tools>/src/utils.cpp <dsk_tools>/src/charmaps.cpp \
    <dsk_tools>/src/viewers/viewer_text.cpp \
    -I<dsk_tools>/src -I<dsk_tools>/include
```

## probes/

Пробы, которыми получены отдельные выводы в `docs/format.md`. Черновики,
сделавшие своё дело, вычищены; осталось то, что ещё пригодится:

| Файл | Назначение |
|---|---|
| `coverage.py` | что из языка ещё не исполняется, с цифрами для раздела «Что дальше» |
| `keywords.py` | таблицы ключевых слов и операндов, прочитанные из интерпретатора |
| `bosgi_font.py` | разбор скана рис. 3.1, сверка с `src/font/koi7-5x8.txt` (нужен Pillow) |
| `disk.py` | вид диска, каталог, файлы данных записями и значениями |
| `dataprobe.py` | перепись файлов данных по всем образам |
| `gbuffer.py` | поиск картинок: поток графического буфера |
| `graphverbs.py` | сопоставление графических глаголов `06 xx` с именами из листингов |
| `hash.py` | хеш имени файла в сектор указателя |
| `overflow.py` | вырождение хеша при числе секторов указателя, кратном трём |
| `forms.py` | матрица форм языка: текст → ожидаемые байты |
| `gen_forms_test.py` | генератор `tests/test_forms.cpp` из этой матрицы |
| `wiki_tokens.py` | сверка вики-статей: таблицы токенов по возрастанию |

Библиотекой они не являются, единообразия в них нет.
