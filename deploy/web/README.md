# Искра 226 — эмулятор Бейсика BASIC 02 в браузере

Это готовый к выкладке пакет: статические файлы, ничего больше. Ни сервера
приложений, ни базы, ни сторонних служб.

## Как выложить

Положить содержимое каталога в корень сайта и раздавать статикой.

**Из файловой системы (`file://`) страница не заведётся** — и это не изъян
сборки: браузер запрещает `fetch` и загрузку модуля WebAssembly с такого
происхождения. Нужен хоть какой-нибудь сервер. Для пробы годится любой:

```
python3 -m http.server 8000
```

Пример настройки nginx с пояснениями, что и зачем, — `nginx.conf.example`.
Коротко, там три вещи: тип `application/wasm` для `.wasm` (в nginx старше
1.21.5 его надо добавить руками), сжатие и осторожный срок кэша.

**Дописывая тип руками, не забудьте `include mime.types` в том же блоке
`types`:** он заменяет унаследованную таблицу целиком, а не дополняет её, и
без включения всё, кроме `.wasm`, уедет с типом `application/octet-stream` —
браузер тогда предложит скачать `index.html` файлом вместо того, чтобы его
показать.

## Что лежит в пакете

```
index.html  iskra.css  app.js  menu.js  keyboard.js   страница
iskra.js  iskra.wasm                                  сам эмулятор
bundle.json                                           названия дисков и программ
*.dsk                                                 образы дискет
programs/*.bas                                        программы примерами
```

## Как добавить свой диск или программу

Положить файл рядом и вписать его в `bundle.json` — оттуда страница и берёт
человекочитаемые названия для меню:

```json
{
  "disks": [
    { "file": "w004-s2.dsk", "name": "Статистика" }
  ],
  "programs": [
    { "file": "programs/raschet.bas", "name": "Расчёт: тригонометрия и ряд" }
  ]
}
```

Диски — плоские образы дискет «Искры»: сектора по 256 байт подряд, всего
256 256 байт. Программы — обычные текстовые листинги в UTF-8.

## Чем эта сборка отличается от настольной

- **Запись на дискету идёт только в память.** Файла у браузера нет, поэтому
  записанное живёт до извлечения дискеты. «Извлечь диск» спрашивает, надо ли
  сохранить образ, если программа на него писала, — и то же спрашивается при
  уходе со страницы.
- **Лист графопостроителя и лента АЦПУ показываются вкладками**, а не
  отдельными окнами: окно, открытое посреди работы программы, погасил бы
  блокировщик всплывающих окон, и вывод пропал бы молча.
- **Лента АЦПУ показывается текстом**, а не знакоместами. На настольной
  сборке видно последние 24 строки, а вся лента — только в файле по ключу
  `--printer`; здесь она видна целиком, ищется, копируется и сохраняется
  кнопкой.
- **Ключ `-i` задаётся адресом**: `?i=1`. Он велит пропускать `ASMB`, `$GIO`
  и вывод на устройство, которого у хоста нет, вместо остановки. Без него
  программа на таком операторе встаёт — молчаливый пропуск сделал бы прогон
  неправдоподобным незаметно для человека.

## Клавиатура

Экранная клавиатура повторяет рис. 2.2 руководства. Слово Бейсика вводится
щелчком по самому слову на клавише; **SHIFT** и **SHIFT LOCK** переключают
второй знак клавиши — латинскую букву или знак.

Обычная клавиатура разложена так же, как в настольных сборках:

| Клавиша | Что делает |
|---|---|
| Esc, F1…F12, PrtScr, ScrLk, Pause | клавиши спецфункций 0…15 |
| с Shift | они же, 16…31 |
| Ctrl+F1…F3 | дубли 13…15 |
| ← → | курсор на позицию, с Ctrl — на пять |
| ↑ ↓ | курсор на строку экрана |
| Insert, Delete, End | INSERT, DELETE, ERASE |
| Ctrl+E, Ctrl+R | EDIT, RECALL |
| Backspace, Ctrl+Backspace | BACKSPACE, LINE ERASE |
| Enter | CR/LF |
| Ctrl+Break | HALT/STEP |
| Ctrl+Enter | CONTINUE |
| Ctrl+N | STMT NUMBER |
| Alt+клавиша | слово Бейсика: Alt+J и Alt+Й дают `FOR` |

Сочетания, забранные самим браузером, до эмулятора не доходят.
