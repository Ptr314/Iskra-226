# Iskra-226 BASIC

Эмулятор Бейсика BASIC 02 советской микроЭВМ «Искра 226» (клон Wang 2200)
и документация по формату её программных файлов.

Программа на диске хранится в двух видах — плоским текстом в КОИ-8 и в
«оттранслированном» токенизированном виде. Эмулятор должен исполнять оба
одинаково.

## Состояние

**Формат разобран**, разбор проверен на корпусе из 94 файлов (15 735 строк
программ, 49 687 операторов) — см. [`docs/format.md`](docs/format.md).

Из эмулятора готово основание: экран БОСГИ (80x24, коды управления,
позитив/негатив), знакогенератор КОИ-8, десятичная арифметика на 13
значащих разрядов, оба разборщика программы и интерпретатор. Сборка —
[`BUILD.md`](BUILD.md).

```
iskra --list w006-s1.dsk               каталог дискеты
iskra --cat  w006-s1.dsk STAT04        листинг программы
iskra --run  w006-s1.dsk STAT04 30 .05 запуск программы с дискеты
```

Первый рубеж взят: `STAT04` исполняется прямо с образа дискеты и из
текстового листинга, давая **побайтово одинаковый экран**. При 30 степенях
свободы и уровне значимости 0.05 программа печатает критерий Стьюдента
2.04 — табличное значение 2.042.

Из языка сделано: `PRINT` (с `AT(`, `TAB(`, `HEX(`, зонами), `INPUT`,
присваивание в несколько целей, `DIM`/`COM`, числовые массивы до двух
измерений, **символьные переменные, массивы строк и `STR(`** (в том числе
слева от знака равенства), функции `LEN`, `NUM`, `VAL`, `POS`,
`FOR`/`NEXT`, `IF`/`THEN`, `GOTO`, `GOSUB`/`RETURN`, `ON … GOTO/GOSUB`,
`STOP`, `END`, `REM`, `SQR`, `ABS`, `INT`, `SGN`, `LOG`, `EXP`, `#PI`.

Плюс `CONVERT` в обе стороны с образами, `LINPUT` и `MAT REDIM`.
Двухбайтовые глаголы (`06 <подкод>`) разбираются структурно все.

Нет `SELECT`, `PRINTUSING`, остальных матричных и графических операторов,
дисковых операторов и `GOSUB'` — из-за них целиком разбирается пока лишь
малая часть корпуса. На неизвестном глаголе разбор останавливается с внятным
сообщением.

## Что здесь лежит

| Каталог | Содержимое |
|---|---|
| `docs/format.md` | журнал исследования формата: токены, таблицы переменных, грамматика операторов, открытые вопросы |
| `docs/ARTICLE-wiki.txt` | статья в разметке MediaWiki для emuverse |
| `docs/DECISIONS.md` | проектные решения по эмулятору и их обоснование |
| `docs/book/` | руководство Баласаняна и др. (1987) и извлечённый из него текст — **вне git**, см. ниже |
| `corpus/hex/` | 79 hex-дампов файлов с фирменных дисков; `*_bin.txt` — токенизированные, `*_text.txt` — текстовые листинги |
| `corpus/bin/` | 43 двоичных файла без текстовых пар |
| `tools/` | питоновская модель разбора: загрузчик, детокенизатор, харнесс построчной сверки |
| `tools/probes/` | одноразовые скрипты, которыми получены отдельные выводы в `docs/format.md` |
| `src/core/` | ядро: экран, перекодировка, граница с хостом; ни SDL, ни Qt, ни dsk_tools |
| `src/font/` | знакогенератор КОИ-8 8x8, 8x14, 8x16 |
| `src/diskio/` | чтение образов дискет — единственный модуль, который видит dsk_tools |
| `src/host_headless/` | хост без окна: автотесты и командная строка |
| `tests/` | автотесты, без сторонних библиотек |
| `libs/dsk_tools` | подмодуль: загрузчики образов дисков, файловые системы, кодировки |

## Источники

Руководство «Программирование на микроЭВМ „Искра 226“» (Баласанян,
Богдюкевич, Шахвердов, 1987) в репозиторий не входит — это скан защищённой
авторским правом книги. Положите PDF в `docs/book/`, текстовый слой
извлекается так:

```
py -m pip install pypdf
py tools/probes/extract_book.py      # или вручную через pypdf
```

Корпус снят с фирменных дисков «Искры»; hex-дампы сделаны DISK Commander.

## Родственные проекты
